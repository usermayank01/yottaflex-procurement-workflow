# Data Dictionary

- Requester: person creating a purchase request.
- Department: organizational owner and approval policy.
- Budget: fiscal allocation for a department.
- PurchaseRequest: procurement demand.
- RequestLine: item/category/quantity/cost detail.
- Supplier: supplier master data and risk/activity state.
- RFQ: request for competitive quotations.
- SupplierQuote: supplier response with landed cost and delivery.
- Approval: request approval record.
- PurchaseOrder: awarded procurement commitment.
- Delivery: delivery lifecycle event.
- WorkflowEvent: immutable audit/state-transition record.
- GroundTruth: separate labels for known anomalies.
